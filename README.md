# Інформаційна система для підтримки процесу паркування автомобілів

Дипломний Django-проєкт для демонстрації роботи інформаційної системи паркування: від пошуку вільного місця та бронювання до QR-контролю доступу, обліку оплат, доплат і формування звітів.

## Мета системи

Система допомагає користувачам знаходити доступні паркомісця, створювати бронювання, керувати власними автомобілями та проходити контроль доступу за QR-кодом. Для персоналу передбачені dashboard, журнал доступу, звіти, керування парковками, паркомісцями й тарифами.

## Основні можливості

- реєстрація, вхід і вихід користувача;
- головна сторінка та сторінка “Про систему”;
- список парковок і глобальний пошук доступного місця;
- сітка паркомісць із візуальними статусами;
- бронювання місця з вибором авто;
- особистий кабінет і “Мій гараж”;
- QR-код бронювання;
- контроль в’їзду та виїзду;
- журнал доступу з фільтрами;
- dashboard адміністратора;
- звіти та CSV-експорт;
- генератор сітки парковки;
- керування паркомісцями й тарифами;
- облік базової оплати, доплат і боргів;
- розділення ролей адміністратора та оператора КПП;
- адаптивний Bootstrap-дизайн.

## Ролі користувачів

**Звичайний користувач**

Може переглядати парковки, шукати місця, додавати авто в гараж, створювати бронювання, переглядати QR-код і власні бронювання.

**Адміністратор**

Має повний доступ до Dashboard, звітів, тарифів, керування парковками, паркомісцями, журналу доступу, контролю пропуску та позначення оплат.

**Оператор КПП**

Має доступ тільки до контролю пропуску, перевірки QR-коду, підтвердження в’їзду/виїзду та журналу доступу.

## Встановлення на Windows

1. Клонувати або відкрити папку проєкту.

2. Створити віртуальне середовище:

```powershell
python -m venv venv
```

3. Активувати virtualenv:

```powershell
.\venv\Scripts\activate
```

4. Встановити залежності:

```powershell
pip install -r requirements.txt
```

5. Виконати міграції:

```powershell
python manage.py migrate
```

6. Створити суперкористувача:

```powershell
python manage.py createsuperuser
```

7. Створити групи ролей:

```powershell
python manage.py setup_roles
```

8. Створити демонстраційні дані:

```powershell
python manage.py seed_demo_data
```

9. Запустити сервер:

```powershell
python manage.py runserver
```

Після запуску сайт буде доступний за адресою:

```text
http://127.0.0.1:8000/
```

## Demo data

Команда:

```powershell
python manage.py seed_demo_data
```

створює демонстраційні групи, користувачів, типи місць, парковки, паркомісця, тарифи, авто та кілька бронювань з різними статусами.

Демо-користувачі:

| Логін | Пароль | Роль |
|---|---|---|
| `admin_demo` | `DemoPass123!` | Адміністратор |
| `operator_demo` | `DemoPass123!` | Оператор КПП |
| `user_demo` | `DemoPass123!` | Звичайний користувач |

## Основні URL

- `/` - головна сторінка;
- `/about/` - про систему;
- `/parkings/` - список парковок;
- `/parkings/search/` - глобальний пошук місць;
- `/accounts/profile/` - особистий кабінет;
- `/vehicles/` - мій гараж;
- `/dashboard/` - панель адміністратора;
- `/reports/` - звіти;
- `/access-control/` - контроль пропуску;
- `/access-control/logs/` - журнал доступу.

## Сценарій демонстрації

1. Відкрити головну сторінку `/` і сторінку `/about/`.
2. Увійти як `user_demo`.
3. Переглянути список парковок і глобальний пошук місць.
4. Відкрити “Мій гараж” і кабінет користувача.
5. Переглянути деталі бронювання та QR-код.
6. Увійти як `operator_demo`.
7. Відкрити контроль пропуску, перевірити QR-код і журнал доступу.
8. Увійти як `admin_demo`.
9. Показати Dashboard, звіти, CSV-експорт, керування тарифами та паркомісцями.
